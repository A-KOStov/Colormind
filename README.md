Colormind - Генератор цветовых схем



Описание:

Colormind - это десктопное приложение для генерации цветовых палитр. 

Оно использует нейросеть через API colormind.io, которая подбирает гармоничные сочетания цветов.



Программа подходит для:

\- Дизайнеров интерьеров

\- Веб-дизайнеров

\- Художников

\- Всех, кто работает с цветом



Как это работает:

1\. Приложение отправляет запрос к API colormind.io

2\. Нейросеть генерирует 5 цветов, которые хорошо сочетаются

3\. Программа показывает цвета



Как запустить:

dotnet build

dotnet run



Функции:

\- Генерация случайной палитры из 5 цветов

\- Простой и понятный интерфейс



Стек технологий:

\- C# .NET 8.0

\- Windows Forms

\- HttpClient

\- API colormind.io
